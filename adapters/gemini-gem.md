# Gemini Gem

1. Create a Gem and paste `adapters/universal-system-prompt.md` (the part below the line) into its instructions.
2. Add as knowledge files: every file in `skills/motion2code/references/` and the templates in
   `skills/motion2code/templates/` (rename to `.txt` if needed).
3. Attach the video or its frames to each request, and ask for a frame-by-frame comparison of the result.

For Gemini CLI, install the extension directly (see the repository README); the CLI reads `SKILL.md` folders.
